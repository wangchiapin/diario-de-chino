# Diario de chino · 我的中文日誌（學生頁與老師後台）

> 給學生看自己的上課行事曆、已上堂數、付費狀況；老師用後台管理「學生電子郵件對照表」。

- **網址：** https://wangchiapin.github.io/diario-de-chino/
- **老師後台：** https://wangchiapin.github.io/diario-de-chino/admin.html
- **Firebase 專案：** moneybook-50481（跟華語教學日誌 cadadiaunosminutos 共用）
- **登入方式：** 學生＝電子郵件＋密碼（要先驗證信箱）；老師＝跟日誌同一組帳號
- **狀態：** 第一階段（課表與付費）完成。第二階段「作業」進行中：已完成「從練習單產生器發布、後台發給學生、學生線上作答與交出、後台線上批改、學生看批改結果」；Word 下載與上傳（批改：看內容、標記、給總分）也做好了；日誌顯示完成狀況之後做。彈跳視窗（練習題、鼓勵、提醒）也做好了。

## 怎麼運作

1. **日誌（cadadiaunosminutos）負責寫入。** 日誌開著時，每分鐘檢查一次，學生資料有變動就複製到 `portal/{老師uid}/students/{學生代號}`；也可以在日誌 ⚙️ 設定 → 🎓 學生頁按「立即更新學生頁」。
2. **老師後台填對照表。** 每位學生填上他登入用的電子郵件，存到 `portal/{老師uid}/roster/{學生代號}`。
3. **學生頁只讀自己那一份。** 學生建立帳號、驗證信箱、登入後，用電子郵件在對照表找到自己，再即時讀自己那一份。

學生看得到的欄位只有：姓名、付費方式（包堂顯示剩幾堂；單堂付費只顯示「單堂付費」）、已上幾堂、所在時區、前 120 天到後 90 天的上課日期與台灣時間。**沒有**收入、匯款、備註、其他學生。

## 作業（第二階段，進行中）

1. **發布**：練習單產生器登入 Google，貼上老師代號，按「發布給學生頁」。完整練習單（含標準答案）存到 `portal/{老師uid}/hwPool/{作業代號}`，只有老師和被允許的發布帳號讀得到。
2. **允許發布帳號**：產生器的 Google 帳號跟日誌的老師帳號在 Firebase 是兩個不同的使用者。後台的「發布帳號」讓老師把產生器顯示的帳號代碼貼進來，允許它發布（存在 `portal/{老師uid}/admins/`）。
3. **發給學生**：後台「作業」清單按「發給學生」，勾選學生。每位學生各拿到一份**只有題目、沒有答案**的複本，存在 `portal/{老師uid}/students/{學生代號}/hw/{作業代號}`（`portal-hw.js` 的 `hwBuildStudent` 負責去掉答案）。同一份作業不能重複發給同一位學生。
4. **學生作答**：學生頁首頁多一張「作業」卡片，點進去依題型作答（九種題型都有）。答案停手約 1 秒自動存到那份作業的 `answers`；按「交出作業」後狀態變 `submitted`，之後鎖定不能改（要重做由老師把狀態改回 `todo`）。老師預覽看得到但不能填、不會寫入。
5. **批改的程式已備好**：`portal-hw.js` 的 `hwAutoGrade` 可對選擇、填空、段落填空、排序、配對、改錯一鍵批改；西翻中、中翻西、造句標成「要老師批改」。

## 時間

- 日誌存的上課時間一律是**台灣時間**（TimeTree 的「課表」）。
- 學生頁每堂課同時顯示「台灣時間」和「你的當地時間」。當地時間用瀏覽器的 Intl 依**那一天**的日期換算，所以有夏令／冬令的國家，換季前後自動正確。
- 學生所在時區：預設用日誌「課表及學生設定」裡選的所在地；沒設定就用學生裝置的時區；學生也可以在頁面最下面自己改（只記在那台裝置）。
- 月曆把課放在**學生當地日期**那一天（台灣早上的課，在美洲常常是前一天晚上）；課的卡片會標「前一天／後一天」。

## 語言

西語（預設）、繁體、簡體，右上角切換。第一次依瀏覽器語言自動選，之後記住。簡體介面仍用台灣用語（只是字形用簡體）。

## 已知限制

- 學生的電子郵件大小寫：對照表一律存小寫，Firebase 登入的電子郵件也是小寫；如果某位學生驗證後還是看不到資料，先檢查對照表裡的拼字。
- 學生在別的分頁驗證信箱後，回到學生頁要按一次「我已經驗證了」才會進去。
- 驗證信、重設密碼信是 Firebase 寄的，有些信箱會放進垃圾郵件匣。

### 批改怎麼用（老師後台）
1. 學生交出後，後台最上面會出現「等你批改」，按「批改」。
2. 選擇、填空、排序、配對、改錯已自動批改好，不對的話點「對／錯」就能改；段落填空點每個空格切換對錯。
3. 西翻中、中翻西、造句：選取學生的文字，按粗體、底線、刪除線、黃／綠／紅底色標記（也可以直接打字修改），再按「對／一半／錯」。
4. 可以寫一句「給學生的話」，按「完成批改」。此時才把對錯、標準答案、你的標記寫進學生那份，學生才看得到。
5. 「退回重做」：學生的答案保留，狀態變回未交。
6. 還沒按完成就離開，內容會暫存在這台裝置，下次開同一份會接回。

### 用 Word 做作業
1. 學生在作業頁按「下載 Word」，頁面當場產生一份空白作業（不含答案）。
2. 學生寫好後「上傳我寫好的 Word」（只收 .docx，最大 600 KB；轉成文字存在 Firestore 的 `students/{sid}/hwFiles/{wid}`，不用 Firebase Storage）。作業沒交出前可以換檔或移除。
3. 老師批改時，如果學生有上傳 Word，批改畫面會顯示他的內容（`vendor/mammoth.browser.min.js` 讀 Word），可以用同樣的標記工具標記，再給一個總分；學生會看到標記後的 Word 和標準答案清單。
4. 規則要加第四批（見規則檔最下面的 hwFiles）。

### 彈跳視窗（練習題、鼓勵、提醒）
- 學生一進頁面，隨機跳出一個：練習題、鼓勵的話或提醒（有題庫／有事才會抽到對應的種類）。學生停留在頁面，**每 5 分鐘再跳出一題練習題**。只有右上角 X 可以關，沒有按鈕、不用作答。正在做作業時不跳。
- 練習題從學生收到的練習單抽（`portal-nudge.js`）：單字（中文＋西文）、語法點，共 5 種：「XXX 的中文怎麼說？」「NNN 是什麼意思？」「用 單字 造一個句子吧！然後傳給 Ben！」「用 語法點 造一個句子吧！然後傳給 Ben！」「你還記得 語法點 怎麼用嗎？」。作業越多，題庫越大。沒有收過練習單就不會出練習題。
- 鼓勵的話預設 20 句（繁／簡／西），含「已上 N 堂」「學了多久」兩句；沒有資料的句子會自動跳過。「學了多久」用日誌「基本資料」裡的「起始上課日期」算（日誌更新學生頁時會一起帶過來），沒填就不會出現那一句。
- 提醒：作業發出滿 3 天沒交、作業批改好了（還沒看過）、今天或明天有課、包堂剩 2 堂以下、單堂付費且今天或明天有課（「上課前記得提前付費唷！」）。
- 老師後台「彈跳視窗」卡片：每位學生可單獨關閉彈跳視窗、關閉繳費提醒；鼓勵的話與提醒的話可以直接修改，或還原成預設。這些設定存在 `roster/{sid}`（開關）和 `config/nudge`（文字，規則見 `moneybook-50481-portal-rules.txt` 第五批）。
- 老師預覽（`?preview=`）也會跳，方便看效果（不會記已看過的批改）。

### 新註冊（學生不用先給信箱）
- 學生用網址註冊並驗證信箱後，如果不在對照表，學生頁會說「已經通知老師了」，並留一筆申請到 `portal/{uid}/requests/{學生 uid}`（只有信箱、uid、時間）。
- 老師後台「學生」分頁最上面會出現「新註冊（N）」，分頁上也有紅點。選出這是哪位學生按「確認」，信箱就寫進對照表（`roster`），學生按「再檢查一次」就能看到資料；不認識的人按「忽略」。
- 為什麼要老師確認：不然任何人都能選別人的名字、看到別人的課表。原本「先向學生要信箱貼進去」的方式也繼續可以用。
- 規則見 `moneybook-50481-portal-rules.txt` 第六批。

### 學習（上課紀錄、複習、能力、教材）

- 學生首頁多一張「我的學習」卡片，打開有四個分頁（`portal-learn.js`）：
  - **上課紀錄**：日誌每堂課的「課程進度」（日誌發佈時帶過來的 `log`，最多 400 筆；「沒上課有付錢」、作業欄、備課備註都不會傳）。最上面有最近一次的「下次進度」預告（`next`）。
  - **複習**：上面三個切換——**卡片**（新學的優先；中文→西文或西文→中文；看意思才翻面，有拼音和🔊聽發音；自己標「我記得／還不熟」，存在雲端 `marks/{sid}`，也備份在這台裝置 `dc.rev.<學生代號>`，可以只複習還不熟的）、**單字總表**（單字、拼音、西文意思）、**語法總表**。總表和卡片的內容 = 練習單裡的單字／語法點自動匯入 + 老師在後台補充（`lists/{sid}`），見 `learnTotals`。
  - **我的能力**：已批改作業數、單字數、語法點數、上課堂數、各題型答對率、最近幾份作業的分數。老師設成「不顯示分數」的作業不算進去。
  - **教材**：Drive 裡這位學生資料夾的 PDF，點了在新分頁打開（讀 `materials/{sid}`）。
- 教材由日誌 repo 的 `apps-script/MaterialsSync.gs` 定時掃描 Drive（一位學生一個資料夾，資料夾名稱要跟日誌的學生名字一樣）後寫入；網頁端不能寫。檔案要設成「知道連結的人都能檢視」，腳本預設會自動設，詳見該檔案開頭的說明。
- 規則見 `moneybook-50481-portal-rules.txt` 第七批（`materials`：老師和該位學生可讀）、第八批（`lists`：老師寫、該位學生讀；`marks`：學生只能讀寫自己的、欄位和大小有限制）。第八批還沒貼之前，學生頁讀不到清單和雲端標記，會安靜地退回「只用練習單＋這台裝置」，不會壞掉。
- 老師後台「單字」分頁：選學生 → 新增單字（一行一個，可只寫中文，也可「中文 西文」）、新增語法點（用＋或換行分開）；拼音照 GoodTeacher 讀音自動帶出（`portal-pinyin.js`＋`gt-readings.json`，從練習單產生器搬來，兩邊要保持一致）；西文意思先查所有學生的練習單和清單裡同一個字，查不到自己填；每個字可以改拼音／意思、隱藏（練習單來的）或刪除（自己加的）；「全部補上拼音」一次補齊；底下看得到學生標的「還不熟」。

### 公布欄、留言板、私訊、紅點

- 學生首頁多一張「公布欄與留言」卡片（`portal-board.js`），點進去三個分頁：
  - **公布欄**（`board/{id}`）：老師在後台「公布」貼，所有學生讀，學生不能寫。
  - **留言板**（`wall/{id}`）：學生寫、所有學生讀，只顯示日誌上的名字；自己的可以自己刪；老師可以刪全部。不用審核。
  - **給老師**（`dm/{id}`）：私訊，只有老師和那位學生讀；一來一往，寫了不能改，老師可以刪。
  - 每則最多 500 字（網頁限制；規則放寬到 1000）。
- 老師後台新增「公布」分頁：貼公告、看和刪留言、回私訊（選單標出每位學生有幾則新的；「已讀」記在 `config/dmSeen`，換裝置也一樣）。分頁標籤有未讀數字。
- **學生名單鏡像 `members/{電子郵件}`**：規則只能判斷「這個人是不是這一位學生」，不能判斷「是不是老師的任何一位學生」，所以後台每次開啟會把對照表（roster）裡有信箱的學生同步成 `members` 文件（`{sid, name}`），多的刪掉、缺的補上；規則用 `exists/get` 查它。信箱要小寫。
- **紅點**：學生首頁的「我的學習」、「公布欄與留言」卡片，和學習／公布欄裡各分頁，有新內容時亮紅點（上課紀錄有新進度、教材有新檔、單字語法變多、有新批改、新公告、別人新留言、老師回覆）。判斷方式：每個項目算一個「內容特徵」，跟學生上次看過時記下的比；記在學生自己的手機（`dc.new.<學生代號>`），第一次來不亮（先記下現在的），資料還沒載入好的項目不判斷。
- 規則見 `moneybook-50481-portal-rules.txt` 第九批。沒貼之前：學生頁讀不到，公布欄卡片整張不顯示；後台「公布」分頁會提醒要加第九批。
- 這次沒有動到 Apps Script 讀的資料（`students`、`materials` 照舊）。

- 「我的能力」單字量與語法點對照（參考用）：`levels-data.js`（TOCFL 八千詞 6 級、HSK 3.0 2021 的 7 級，詞→級）、`grammar-map.js`（文法速查表標題→冊→CEFR 範圍），第一次打開「能力」才讀。連續達標 75%、對到 30 字以上才評估。老師後台「起始程度」存在 `lists/{sid}.start`（`{cefr, words, note}`）；「語法點分冊」手動對照存在 `config/gmap`（`{map:{標題:冊}}`，0＝不分類），都用原有規則，不用加新規則。

- 能力分級測驗（`placement.js`、`placement-bank.js`、`placement.html`）：題庫 A1–C2 每級單字 10、語法 10、短文 2 篇×2 題；快速版約 20 題（先 8 題粗估再 12 題考邊界附近）、完整版 48 題；每級答對六成才算過。學生頁（「我的能力」）和獨立網頁（`placement.html?t=老師代號`，要填名字）測完都會自動存到 `portal/{tid}/placements/{id}`（欄位：src、sid、name、mode、ts、reached、cefr、tocfl、right、total、by、py）。後台「測驗」分頁列出全部、可刪除；學生頁只讀自己的（`sid` 對得上）。老師專用備註存在 `portal/{tid}/notes/{sid}`（後台「單字」分頁每位學生一張卡片）。**這兩個要加規則：見 `moneybook-50481-portal-rules.txt` 第十批。** 題庫是用 `build_bank` 程式從審好的題庫檔轉成（含繁體、GoodTeacher 拼音）。
