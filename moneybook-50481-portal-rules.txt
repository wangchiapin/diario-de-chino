// ===== Firebase 專案 moneybook-50481：學生頁（diario-de-chino）要加的 Firestore 規則 =====
// 這只是「要加的那一段」。專案的規則整個只有一份，所以要在「目前線上的完整規則」裡加上去，不要整份換掉。
// 加的位置：放在 match /databases/{database}/documents { 裡面，跟其他 match 並排。
// 連接的 repo：diario-de-chino（學生頁與老師後台）、cadadiaunosminutos（日誌，負責寫入學生資料）。
// 最後更新：2026-11-11 14:38（新增 students/{sid}/hwFiles：學生用 Word 交作業的檔案）
// 變更紀錄（只留最新 3 筆，新的放最上面；每次改規則都要寫日期＋時間）：
//   - 2026-11-11 14:38 新增 portal/{tid}/students/{sid}/hwFiles（學生上傳的 Word，轉成文字存放；學生只能在作業還沒交時寫自己的）
//   - 2026-11-11 11:02 students/{sid}/hw 加學生更新規則（只能改 answers、status、submittedAt，且只有還沒交的）
//   - 2026-11-11 10:52 新增 portal/{tid}/admins、hwPool、students/{sid}/hw（作業，第一步：發布與發給學生）
//
// 誰能做什麼：
//   - 路徑裡的 {tid} 就是老師（你）的 uid。只有老師自己能寫、能讀底下全部。
//   - 學生只能讀「自己那一份」：電子郵件已經驗證過，而且跟老師填在對照表（roster）裡的一樣。
//   - 學生唯一能寫的，是自己那份作業的答案和「交出」（見最下面）；讀不到收入、匯款、備註、別的學生（那些在別的路徑，規則本來就只給本人）。

    // 學生頁：日誌複製過來的「每位學生自己那一份」（姓名、付費、剩幾堂、已上幾堂、時區、上課日期時間）
    match /portal/{tid}/students/{sid} {
      allow read: if request.auth != null && (
        request.auth.uid == tid ||
        (request.auth.token.email_verified == true &&
         get(/databases/$(database)/documents/portal/$(tid)/roster/$(sid)).data.email == request.auth.token.email));
      allow write: if request.auth != null && request.auth.uid == tid;
    }
    // 對照表：學生電子郵件 ↔ 日誌學生。學生只能查到「電子郵件是自己的」那一筆（用來找出自己是哪位學生）
    match /portal/{tid}/roster/{sid} {
      allow read: if request.auth != null && (
        request.auth.uid == tid ||
        (request.auth.token.email_verified == true && resource.data.email == request.auth.token.email));
      allow write: if request.auth != null && request.auth.uid == tid;
    }


// ===================================================================
// 第二批（作業）：已經貼過上面兩段的話，只要再貼下面這三段，貼在上面兩段的後面，一樣跟其他 match 並排。
// ===================================================================

    // 發布帳號：老師允許的帳號（例如練習單產生器登入的 Google 帳號）。只有老師本人能增減。
    match /portal/{tid}/admins/{aid} {
      allow read, write: if request.auth != null && request.auth.uid == tid;
    }
    // 作業原稿（含標準答案）：只有老師，和老師允許的發布帳號可以讀寫。學生完全讀不到。
    match /portal/{tid}/hwPool/{wid} {
      allow read, write: if request.auth != null && (
        request.auth.uid == tid ||
        exists(/databases/$(database)/documents/portal/$(tid)/admins/$(request.auth.uid)));
    }
    // 發給每位學生的那一份（只有題目，沒有答案）：學生只讀自己的；老師全部讀寫。
    // （學生交作業的寫入規則，下一步做學生作答時再加。）
    match /portal/{tid}/students/{sid}/hw/{hid} {
      allow read: if request.auth != null && (
        request.auth.uid == tid ||
        (request.auth.token.email_verified == true &&
         get(/databases/$(database)/documents/portal/$(tid)/roster/$(sid)).data.email == request.auth.token.email));
      allow write: if request.auth != null && request.auth.uid == tid;
      // 學生作答：只能改 answers、status、submittedAt；只有「還沒交」(todo) 的作業才能改；status 只能是 todo 或 submitted。
      // 交出後就鎖住，要重做由老師把 status 改回 todo。
      allow update: if request.auth != null
        && request.auth.token.email_verified == true
        && get(/databases/$(database)/documents/portal/$(tid)/roster/$(sid)).data.email == request.auth.token.email
        && resource.data.status == 'todo'
        && request.resource.data.diff(resource.data).affectedKeys().hasOnly(['answers', 'status', 'submittedAt'])
        && request.resource.data.status in ['todo', 'submitted'];
    }


// ===================================================================
// 已經貼過第二批的話：不用重貼整份。只要把線上規則裡
// 「match /portal/{tid}/students/{sid}/hw/{hid} { ... }」那一整段，換成上面這個新版本
// （差別只有最後多了 allow update 那一段，學生才能存答案和交出作業）。
// ===================================================================


// ===================================================================
// 第四批（Word 上傳）：只要「新增」下面這一段，貼在其他 match 旁邊（跟上面一樣並排）。
// 不用動前面的任何一段。
// ===================================================================

    // 學生用 Word 交作業：Word 檔轉成文字（b64）存在這裡，一份作業一個檔。
    // 老師全部讀寫；學生只能讀、寫「自己的」，而且只有作業還沒交（todo）時才能新增、換檔、刪除；檔案文字要小於約 600KB 的檔案。
    match /portal/{tid}/students/{sid}/hwFiles/{wid} {
      allow read: if request.auth != null && (
        request.auth.uid == tid ||
        (request.auth.token.email_verified == true &&
         get(/databases/$(database)/documents/portal/$(tid)/roster/$(sid)).data.email == request.auth.token.email));
      allow write: if request.auth != null && request.auth.uid == tid;
      allow create, update: if request.auth != null
        && request.auth.token.email_verified == true
        && get(/databases/$(database)/documents/portal/$(tid)/roster/$(sid)).data.email == request.auth.token.email
        && get(/databases/$(database)/documents/portal/$(tid)/students/$(sid)/hw/$(wid)).data.status == 'todo'
        && request.resource.data.keys().hasOnly(['b64', 'name', 'size', 'at'])
        && request.resource.data.b64 is string
        && request.resource.data.b64.size() < 850000;
      allow delete: if request.auth != null
        && request.auth.token.email_verified == true
        && get(/databases/$(database)/documents/portal/$(tid)/roster/$(sid)).data.email == request.auth.token.email
        && get(/databases/$(database)/documents/portal/$(tid)/students/$(sid)/hw/$(wid)).data.status == 'todo';
    }
